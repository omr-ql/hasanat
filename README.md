# حسنات

Offline dhikr counter. Counts stay on the device with Hive. The app does not use the network.

The home screen starts with استغفر الله، الحمد لله، سبحان الله، الله أكبر، and الصلاة على النبي. Anything else can be added under أذكاري.

```bash
flutter pub get
flutter run
```
